# 屋号・店舗名変更 テスト版

index.htmlから確認してください。フォルダ全体を独立したテスト公開先へ配置できます。

- 旧LPのバナーは屋号・店舗名変更向けです。PCは既存のヒーローフォーム、スマートフォンはモバイルフォームへ移動し、店舗名変更を選択済みにします。
- 店舗名変更の専用フォームページは設けません。
- 既存のヒーロー／モバイル／電話予約／キャンペーン確認フォームに、屋号・店舗名変更の選択肢を追加しています。
- 新LPは従来の店頭価格バナー・遷移先を維持します。
- 送信はブラウザ内の模擬動作です。メール送信・マスタ登録・本番計測は行いません。
- mail.phpは送信を拒否するテスト専用ファイルです。本番へ上書きしないでください。
- 入力はこのタブのsessionStorageに一時保存します。テスト用の情報で確認してください。
- 本番反映時はPHP側の受付条件、メール・GAS項目、計測イベントの実装が別途必要です。

## GitHub Pagesで共有する場合

このフォルダを画像を含めて丸ごとGitに追加してください。相対パスで参照しているため、同じ構造を保てばリポジトリのサブフォルダでも表示できます。

- 画像・CSS・JavaScript・faviconをすべて含めます。ルートの.gitignoreにこのテスト環境の画像を追跡する例外を設定しています。
- フォルダ内のindex.htmlがクライアント向けの確認ページです。GitHub Pagesの公開URLに、このフォルダまでのパスと/index.htmlを付けて共有します。
- リポジトリの公開対象がrootの場合は、ルートの.nojekyllもGitに追加してください。
- GitHub PagesではPHPを実行しません。このテスト版はJavaScriptで模擬送信を行うため、確認できます。
- mail.phpは外部送信を行わない拒否用のダミーです。本番の送信コードや認証情報は含みません。
- Google Fonts・郵便番号検索・LINEのリンクなど、既存の外部サービスはインターネット接続が必要です。

### ブラウザからのアップロード

新旧LPは1フォルダずつ、別々にアップロード・コミットしてください。2フォルダとルート設定ファイルをまとめてアップロードすると、GitHubの100ファイル制限を超えます。リポジトリ内の08.テスト環境を開き、このフォルダ自体をドラッグすると階層を保てます。ルートの.gitignoreと.nojekyllは別途追加してください。
