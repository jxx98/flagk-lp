# モバイルサポート改善・旧LP テスト版

「店舗名変更-旧LP」から複製した、独立した確認用フォルダです。
元フォルダ・本番ファイルは変更していません。

## 最新版の内容

- モバイルの比較セクションを、直接契約の案内と3つのサポートに変更。
- 店舗様とFlagKの役割を明示。申込の流れと実績カードを横組みに変更。
- 対応業態の例をグレーの枠とタグで表示。
- スマホの本文15px・項目見出し17px・注記12pxを基本に整理。
- FAQの質問は15px。ヒーロー補足2文はサイズ・太さを統一。
- 出店開始の枠は緑、横組み、店舗様の枠と同じ寸法。
- デザイン変更はindex.html内。画像・CSS・JSは必ず同梱してください。

## 既存のGitHub Pagesへアップロードする場合

1. リポジトリの「08.テスト環境」を開きます。
2. 「Add file → Upload files」で、この「モバイルサポート改善-旧LP」フォルダを丸ごとドラッグします。
3. 画像、CSS、JS、faviconと、隠しファイルの.gitignoreが含まれていることを確認してコミットします。
4. 既存のGitHub Pagesの公開処理が完了したら、次の形式のURLを携帯のブラウザで開きます。

https://ユーザー名.github.io/リポジトリ名/08.テスト環境/モバイルサポート改善-旧LP/index.html

- ZIPファイル自体をアップロードしてもWebページにはなりません。解凍したフォルダをアップロードしてください。
- 既存リポジトリの公開元がブランチのrootである想定です。公開元がdocsなら、その配下へ配置してください。
- 公開元のルートに.nojekyllを置きます。既存のFlagKルートには配置済みです。
- 新しいリポジトリへこのフォルダの中身を直接置く場合は、Settings → Pagesで、SourceをDeploy from a branch、Branchをアップロード先ブランチ、フォルダを/(root)に設定します。
- 正式な公開URLはリポジトリのSettings → Pagesで確認してください。
- GitHubのページURL（github.com）ではなく、Pagesの公開URL（通常github.io）を開きます。

## 携帯での確認

今の127.0.0.1:8767は、このMac内だけの確認用URLです。携帯ではGitHub Pagesの公開URLを開いてください。
更新前の画面が残る場合は、index.html?v=6 のようにクエリを付けて再表示します。

## フォームの動作

- フォーム送信はブラウザ内の模擬動作です。メール送信・マスタ登録・本番計測は行いません。
- mail.phpは送信を拒否するテスト専用ファイルです。
- 入力内容はタブのsessionStorageに一時保存します。テスト用の情報で確認してください。
- GitHub PagesではPHPは実行されません。JavaScriptで模擬送信を確認できます。
- LINE・電話のリンクは既存の外部連絡先へつながります。
- Google Fonts・郵便番号検索は既存の外部サービスを使用します。
- この一式は確認用です。本番の送信処理へ上書きするファイルではありません。
