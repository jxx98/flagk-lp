# HP ニュース・公式LINEテスト

`deploy/` を複製したテスト用のHPです。公開中のHPには影響しません。

- 対象: トップページのニュースセクション
- 変更: ニュースを1件のみ表示（開閉なし）
- 変更: 全ページで使える「LINEで相談」固定ボタンを追加
- 挙動: スマホはLINEへ遷移、PCはQRコードをモーダル表示
- 変更: お問い合わせフォーム上には、LINE相談への補助ボタンを配置
- 検索エンジン: `robots.txt` でクロールを拒否

確認後に本番へ反映する場合は、この `index.html` のニュースセクションを `deploy/index.html` へ移植します。
