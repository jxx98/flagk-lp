# 店舗名・屋号変更の案内追加テスト版：申込LP

複製元：モバイルサポート改善-旧LP。複製元・本番ファイルは変更していません。
index.html、name-change-guide.css、name-change-guide.jsを編集しています。
上部案内リンク → FAQ直前の説明 → 既存フォームの「屋号・店舗名変更」を選択する導線です。
フォームは既存テスト版の模擬送信です。メール・マスタ・本番計測は行いません。

## 運用の根拠（2026-10-16更新）

ユーザー提示の「10/13 お知らせ事項：【重要】業態変更・屋号変更に伴う業務フロー変更のお知らせ」の画像を根拠に、案内を更新しました。
画像に年と発行元の記載はないため、「2026年10月からサポートで変更できない」との一律な断定は掲載していません。
- 屋号・業態変更は代理店経由の「新規TU」として登録する運用。LPでは一般向けに「新規登録」と表記。
- 資料上は注文履歴・レビュー・評価が引き継ぎ不可。ユーザーの指示により、LP本文・詳細欄には掲載していません。
- 必須書類：営業許可証、変更届、新屋号を確認できる外観写真または店舗リンク。
- 保健所で変更届不要とされた場合でも、変更届の提出が必要。
- 社内の運用事項：進行前にAMへ事前確認・連携すること、店舗様の了承を得てから進行すること。
- 今回の変更は案内コンテンツのみ。既存フォームの項目追加や同意チェックの追加はしていません。

## 公開確認

フォルダを画像・CSS・JSごとアップロードしてください。index.html単体では表示できません。
既存のLPを上書きせず、このフォルダを別のテスト公開先に置いてください。
GitHub Pagesの公開元ルートには.nojekyllを置きます。
検討LP・申込LPはファイル数が多いため、Webでアップロードする場合は1フォルダずつコミットしてください。
