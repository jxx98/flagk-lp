FlagK / Uber Eats 法人向け代理店募集LP
更新：2026-10-26

■ 内容
法人限定の二次代理店募集。営業アポイントを連携し、FlagKがクロージングと掲載作業を担当。
初期費用・加盟金・研修費0円。報酬の具体的な単価・成果条件・支払い時期は個別にご案内。
取次成果率90％は提供資料に基づく仮表記。集計条件は公開前に確認。
RocketNowの売上事例は撤去し、提供資料に基づく「紹介から始める収益モデル」へ変更。
広告配信先の東京23区を、募集エリアの制限として扱っていません。
PC・スマートフォン対応。既存のNoto Sans JPとロゴを使用。
ヘッダー18px（中間幅16px／スマホ15px）、本文16px、CTA16px、補足14px以上。
モバイルの入力欄16px、ボタン高さ48px以上。フォーム閲覧・入力中は下部固定CTAを隠す。
装飾英語、制作確認表示、画像の注記は表示しません。

■ ローカル確認と本番送信
index.htmlを開けば表示・入力確認ができます。
実送信にはPHP 7.4以上とSMTP接続が必要です（保守中のPHP 8系を推奨）。
Gitへの保存やアップロードだけでは、送信機能は動きません。
GitHub Pagesや静的なHTMLホスティングではPHPを実行できません。
PHP非対応・設定未完了時は、受付完了として扱わずエラーとメール窓口を表示します。

■ 配置方法（既存のXserver等）
1. このフォルダ一式を、既存ドメインのpublic_html直下の専用サブフォルダへ配置。
   index.html、app.js、analytics.js、styles.css、mail.php、thanks.php、assets/、vendor/を配置。
2. 既存LPと同じ flagk-mail-config.php をpublic_htmlと同階層に維持。
   SMTP設定の中身・パスワードはこの成果物には含めていません。
   配置が異なる場合、サーバー環境変数 FLAGK_SMTP_CONFIG_PATH で非公開の絶対パスを指定。
   公開ディレクトリ内の設定ファイルは読み込みを拒否します。
3. セッション保存先とPHPの一時ディレクトリへの書き込み、SMTP接続を確認。
4. 宛先は既存LPと同じ ubereats-support@flagk-co.jp。
   件名「【法人代理店募集】Uber Eats 加盟店開拓のご相談」で区別します。
5. 送信機能の確認時は、管理者自身が実送信し受信を確認。
   自動返信はありません。既存の店舗用スプレッドシートへは書き込みません。
6. 新規ページの公開URLが決まり次第、canonical / og:urlをそのURLで設定。
   index.htmlはindex,follow、thanks.phpはnoindex。
   検索未公開のステージングではホスティング側のアクセス制限を使用してください。
7. 既存サーバーに適用されているリダイレクト・ルーティングが専用サブフォルダに干渉しないか確認。

■ フォーム
必須項目と法人・個人情報保護方針への同意をブラウザとサーバーの両方で検証。
確認 → 明示的な送信 → SMTP受付後のみ完了画面、の順です。
セッションとトークンによるCSRF対策、honeypot、IP単位のレート制限、二重クリック防止、
同じ受付IDの再送防止を実装。失敗時は入力を保持して再試行できます。
メール送信ライブラリは既存LPのPHPMailerを同梱（vendor/phpmailer/src）。
サーバーのSMTP受付成功は、受信箱への到達を保証しません。迷惑メール等も含め受信確認が必要です。
個人情報保護方針・運営会社は既存FlagKの公開ページへのリンクを使用。

■ 計測
HTTPSのflagk-co.jpまたはそのサブドメインでのみ、既存GA4 G-VLQG12Y4E5へ接続。
file://やlocalhostでは外部に計測を送らず、dataLayerでイベントを確認できます。
フォームの氏名・会社名・電話・メール・本文はGA4へ送りません。
ページURL・参照元URLはクエリとフラグメントを除いて設定します。

partner_cta_click     : header / hero / middle / mobile_sticky の位置別クリック
partner_section_view  : 各セクションの初回表示
partner_form_start    : 初回入力
partner_form_review   : 入力確認へ進む
partner_form_error    : 送信エラー
 generate_lead        : サーバーが受付を確認した完了画面のみ（受付IDで再読込の重複を抑止）

GA4でgenerate_leadをキーイベントに設定し、lp_variant=partner_recruitmentで区別してください。
既存の店舗募集用Google広告コンバージョンラベルは流用していません。
新しい広告アクションを作成する場合は、GA4キーイベントのインポート等を管理画面で設定してください。

■ 法人の有効問い合わせ・商談・契約の評価
